XTTS v2 – Example command

docker compose run --rm xtts python -c "
from TTS.api import TTS

# Load text from file
with open('/input/text.txt', 'r', encoding='utf-8') as f:
    text = f.read()

# Load XTTS v2
tts = TTS('tts_models/multilingual/multi-dataset/xtts_v2')

tts.tts_to_file(
    text=text,

    # Built-in voice
    speaker='Ana Florence',

    # Or use a custom reference voice:
    # speaker_wav='/input/my_voice.wav',

    # Language
    language='en',

    # Speech speed
    speed=0.85,

    # Voice variation / randomness
    temperature=0.7,

    # Reduces unwanted repetitions
    repetition_penalty=5.0,

    # Number of possible candidates considered
    top_k=50,

    # Probability threshold for candidate selection
    top_p=0.85,

    # Automatically split long texts into sentences
    split_sentences=True,

    # Output
    file_path='/output/test.wav'
)
"


Parameter overview
-------------------

temperature
    Voice variation / randomness
    Typical range: 0.3 - 0.8
    Lower = more consistent and calm
    Higher = more variation, but can sound less stable

speed
    Speech speed
    Typical range: 0.8 - 1.0

top_k
    Number of possible candidates considered
    Typical range: 20 - 100

top_p
    Probability threshold for candidate selection
    Typical range: 0.7 - 0.95

repetition_penalty
    Helps prevent unwanted repetitions
    Typical range: 2 - 10

split_sentences
    Automatically splits longer texts into sentences
    True


Example: calm narrator
----------------------

speed=0.85
temperature=0.5
top_p=0.8
top_k=50
repetition_penalty=5.0


Example: slightly more lively
-----------------------------

speed=0.9
temperature=0.7
top_p=0.9
top_k=80
